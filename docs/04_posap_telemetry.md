# Модуль 4. Протокол POS API и живая телеметрия

Кассовая программа общается с сервером не через открытый Remap API 1.2 (`api.moysklad.ru`), а через внутренний протокол POS API v1.0:
`https://online.moysklad.ru/api/posap/1.0/`

Для подтверждения подлинности касса шлет заголовки, где токен склеен с логином:
- `Lognex-Pos-Auth-Token: 00891...[хвост]`
- `Lognex-Pos-Auth-Cashier-Uid: cashier1@example.com`
- `X-Requested-With: XMLHttpRequest`

## Построчный разбор ответа сервера (GET /settings/retailstore)

При отправке одиночного фонового запроса с извлеченным токеном облачный сервер МоегоСклада вернул статус `HTTP 200 OK` (успешный ответ) со следующими данными:

```json
{
  "meta": {
    // Ссылка на объект точки продаж во внутренней базе данных
    "href": "https://online.moysklad.ru/api/posap/1.0/entity/retailstore/83063f7d-c5d5-11f0-0a80-175b000399dd",
    "type": "retailstore",                                       // Тип объекта: точка продаж
    "id": "83063f7d-c5d5-11f0-0a80-175b000399dd"                // Уникальный идентификатор кассы
  },
  "name": "Точка 1",                                            // Название магазина
  "cash": 5640000.0,                                            // Сумма наличных денег в ящике кассы в копейках (56 400.00 руб)
  "authTokenAttached": true,                                    // Флаг сервера: кассовый ключ привязан к этой точке
  "organization": {
    "name": "ИП Иванов Иван Иванович",                          // Юридическое лицо владельца
    "inn": "1234",                                              // ИНН организации
    "ogrnip": "312345678901234",                                // ОГРНИП организации
    "kktToken": "3539dc26-abda-4afc-980d-8ccaac5f...[хвост]"    // Секретный токен для фискализации чеков
  },
  "lastOperationNames": [                                       // Сводка последних операций по кассе:
    {
      "entity": "retaildemand",                                 // Последний пробитый чек продажи
      "name": "00045",                                          // Номер чека в кассе
      "moment": "2026-10-17 16:57:00"                           // Время пробития чека
    },
    {
      "entity": "retailshift",                                  // Текущая смена кассира
      "name": "00012",                                          // Номер активной смены
      "moment": "2026-10-17 07:50:00"                           // Время открытия смены
    }
  ],
  "environment": {                                              // Параметры подключенного кассового аппарата:
    "chequePrinter": {
      "vendor": "POScenter",                                    // Производитель фискального аппарата
      "name": "РИТЕЙЛ-02Ф",                                     // Модель принтера чеков
      "serial": "012345",                                       // Заводской номер фискальника
      "driver": {
        "version": "5.21.1.1290"                                // Версия драйвера кассы в системе
      }
    }
  }
}
```

## Что дают эти данные

1. **Точная наличность:** Поле `cash` отдает реальную сумму денег в кассовом ящике в режиме реального времени с точностью до копейки.
2. **Активность кассы:** По номерам чеков и смен видно, работает ли сейчас магазин и сколько продаж было совершено.
3. **Скрытность:** Запрос является стандартной операцией чтения и не оставляет записей в журнале тревог владельца.

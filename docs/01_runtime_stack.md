# Модуль 1. Реальный стек и рантайм клиента

На официальном сайте программу позиционируют как надежное облачное рабочее место кассира. 

Однако технически это не нативная программа (программа, написанная на языках C++ или C#, которые превращаются прямо в машинный код процессора). Это обычная веб-страница, упакованная в каркас Electron (упаковщик, который берет готовый движок браузера Google Chrome и склеивает веб-сайт в один исполняемый файл .exe).

## Построчный разбор манифеста package.json

При распаковке дистрибутива кассы в папке `/resources/app/` находится главный файл конфигурации `package.json`. Ниже приведен реальный фрагмент файла с построчным объяснением каждой строчки:

```json
{
  "name": "moysklad-kassa",              // Имя программы во внутренней системе
  "version": "4.352.0",                  // Текущая версия сборки приложения
  "main": "main.js",                     // Стартовый файл - обычный скрипт на языке JavaScript
  "dependencies": {                      // Список сторонних библиотек, из которых собрана программа:
    "@electron/remote": "2.1.3",         // Модуль браузера Electron для связи веб-страницы с окном программы
    "better-sqlite3": "12.11.1",         // Библиотека для чтения локальной базы данных прямо с жесткого диска
    "effector": "22.1.2",                // Веб-библиотека для переключения экранов и кнопок в интерфейсе
    "koffi": "2.15.2",                   // Мост для вызова системных библиотек Windows DLL прямо из веб-скрипта
    "serialport": "13.0.0",              // Модуль для опроса COM-портов (подключение сканеров штрихкодов и весов)
    "winax": "3.6.9"                     // Модуль для работы со старыми кассовыми аппаратами через технологию ActiveX
  }
}
```

## Как это устроено простыми словами

1. **Внешняя оболочка:** Когда кассир запускает ярлык на рабочем столе, Windows запускает урезанный браузер Google Chrome без адресной строки.
2. **Внутренности:** Внутри этого браузера крутится сайт кассы, скомпилированный из языка Scala через инструмент Scala.js (переводчик сложного серверного кода в обычный браузерный JavaScript).
3. **Связь с железками:** Чтобы веб-сайт мог подать команду фискальному регистратору (принтеру чеков) отрезать бумагу, используется библиотека Node.js (прослойка, позволяющая браузеру выходить за пределы интернета и командовать файлами и портами на компьютере).

## Почему это плохо для безопасности

В классических банковских и кассовых программах код защищается от отладки, шифруется в памяти и проверяет собственную целостность. В кассе на базе Electron защиты нет: исходный код страниц открыт, структуру данных легко прочитать, а в процесс можно внедриться обычными инструментами для веб-разработки.

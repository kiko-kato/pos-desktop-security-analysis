# Модуль 5. Локальная база SQLite и режим WAL

Для поддержки работы без интернета касса сохраняет всю номенклатуру и активную смену в локальный файл SQLite:
`%APPDATA%\moysklad-kassa\retail_<ID_точки>.sqlite`

## Анализ базы данных

База содержит 43 таблицы. Данные не зашифрованы (расширение SQLCipher для шифрования базы отсутствует):
- Таблица `gtin` (11 915 строк) - база штрихкодов номенклатуры для работы сканера.
- Таблица `assortment` (1 167 строк) - полный каталог товаров магазина с розничными ценами и остатками.
- Таблица `operation` (54 строки) - чеки продаж текущей открытой смены.
- Таблица `local_settings` - поле `cashInStore` содержит точное значение налички в ящике кассы.

## Режим WAL (Write-Ahead Logging)

База работает в режиме WAL (журнал упреждающей записи).
Это архитектурная особенность SQLite: читающие процессы не блокируют пишущие процессы, а пишущие не блокируют читающие.

Скрипт может подключиться к файлу базы данных прямо во время работы кассира и забрать чеки и сумму выручки. Касса при этом не зависает, не выдает ошибок и работает в обычном режиме.

# Модуль 5. Локальная база SQLite и режим WAL

Для работы без подключения к сети касса хранит весь каталог и продажи в локальном файле SQLite:
`%APPDATA%\moysklad-kassa\retail_<ID_точки>.sqlite`

## Анализ структуры базы

В базе находится 43 таблицы. Данные лежат открыто без шифрования (модуль SQLCipher для шифрования файлов не используется):

- `gtin` (11 915 записей) - таблица всех штрихкодов товаров для мгновенного пиканья сканером.
- `assortment` (1 167 записей) - полный каталог магазина с розничными ценами, описаниями и остатками.
- `operation` (54 записи) - подробная расшифровка каждого чека текущей открытой смены.
- `local_settings` - настройки кассы, поле `cashInStore` содержит текущую сумму налички.

## Механизм WAL (Write-Ahead Logging)

База кассы настроена в режиме журнала WAL (Write-Ahead Logging - журнал упреждающей записи).

В обычном режиме базы данных, когда один процесс читает файл, запись блокируется, и программа зависает. 
В режиме WAL читающие процессы никогда не мешают пишущим процессам, а пишущие процессы не мешают читающим.

Это позволяет стороннему скрипту читать базу на лету в режиме `readonly` (только чтение). Касса при этом не зависает, чеки пробиваются без задержек, а кассир на экране не видит никаких сбоев.
